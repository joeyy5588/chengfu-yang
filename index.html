Research interests

LATEST · 2026Preprint · Under submission

OpenVLHarness

Real World Visual Agentic Tool-Use with Multimodal Memory

We build a general multimodal reasoning harness with task-level perception tools and persistent multimodal memory. It lets models gather visual evidence, inspect artifacts, and use code across reasoning steps—without additional model training.

22 benchmarks · +9.7–12.6 points across model backbones
